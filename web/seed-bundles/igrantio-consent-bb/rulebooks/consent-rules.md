# Consent rulebook (ISO/IEC 27560 profile)

## C1 - Explicit and informed
The consent prompt must list the exact data fields, the purpose, and the
retention period before the individual can accept.

## C2 - Minors
Individuals under 18 require a guardian consent record; the guardian
relationship must be verifiable in the National Learner Registry.

## C3 - Revocable
Revocation must be one action away in any UI that displays consented data,
and must take effect immediately.

## C4 - Receipts
Every grant and revocation produces a consent receipt id which is stored in
the application audit log.

## C5 - No dark patterns
Decline must be as prominent as accept. Pre-ticked boxes are prohibited.
